# ♞ Chess Quest
A kid-friendly chess teaching app: piece lessons with star challenges, a Move Coach (good / okay / risky moves with kid explanations), puzzles from famous games (each replayed from move 1 and checked with chess.js + Stockfish, see `build.cjs`), and play vs the computer (Easy / Medium / Hard). Static HTML/JS, works offline after first load. Licenses: see CREDITS.md.
